# 품질 게이트 — aing 어드바이저 검수 기준

마지막 수정 2026-10-20. 컴포넌트·변형은 이 검수를 통과해야 레지스트리에 들어간다.

**기준선(사용자 지정): 모든 제품 UI는 21st.dev 같은 종류 컴포넌트와 동등하거나 그 이상이어야 한다.** 예: AI 채팅은 https://21st.dev/?qt=ai-chat 의 추천 상위 컴포넌트(캡처: `.verify/refs/21st-ai-chat-*.png`). 다른 종류는 `https://21st.dev/?qt=<종류>`(button, select, dialog, table, radio …)의 추천 상위 3–5개를 어드바이저가 그때 캡처해 비교 기준으로 삼는다. Kokonut·Cult·Animate UI는 보조 기준.
검수자는 **aing 어드바이저**(`.claude/agents/aing-advisor.md`, Claude Opus)다. 구현자(Codex)는 자기 결과를 채점하지 않는다 — 역할 분리.

## 판정

| 결과 | 조건 |
|---|---|
| **ACCEPT** | 총점 ≥ 85, 모든 영역이 배점의 60% 이상, 차단 항목 0 |
| **REVISE** | 70–84점, 또는 한 영역이 60% 미만. 고칠 목록(구체적 위치·기대 모습)과 함께 반려 |
| **REJECT** | < 70점 또는 차단 항목 1개 이상. 다시 설계 |

같은 항목이 두 번 REVISE되면 코디네이터가 배치(모델·effort)를 한 칸 올리거나 설계를 다시 본다.

## 차단 항목 (하나라도 있으면 REJECT)

- 콘솔 에러·하이드레이션 경고·Next dev "Issue"
- 375px 가로 넘침
- 이중 포커스 링, 포커스가 안 보임
- 본문 대비 AA 미달
- 키보드로 조작 불가한 기능
- 크기 예산 초과
- 21st.dev 같은 종류 추천 상위보다 명백히 못함(어드바이저가 비교 이미지로 판단)
- 측정하지 않은 수치를 문서에 적음
- 줄을 합쳐 줄 수 한도를 맞춤(한 줄 100자 초과)
- 이름만 다른 판(Tailwind판이 CSS판과 사실상 같음)
